# Learning Log

> Traps only: failure mechanisms that a later edit of the same files would hit again and that no
> test, rule or code comment prevents. Each entry is symptom — mechanism — guard, with the paths it
> applies to.
>
> **Read** before editing a file: search for its path and feature directory
> (`rg -n '<path>' docs/LEARNING_LOG.md`) and read the entries that match. Never read the whole log
> or a whole category.
>
> **Write** only through the `post-task-learning` skill, and only for a trap nothing else captures
> (`.claude/rules/post-task-learning.md`). A lesson that can be a check, a rule or a code comment
> goes there instead.
>
> Entries cite paths as they were on their date; confirm them in source.
